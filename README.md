# R-Studio-Graphing-Relationship-Project
U.S. Presidential Vote Analysis (2008–2024) – R Data Science Project
Conducted an exploratory data analysis of U.S. presidential election vote shares by state from 2008 to 2024 using R. Transformed the dataset into long format for analysis of Democratic and Republican vote proportions and computed summary statistics to identify temporal voting trends, including changes in Trump vote share across multiple election cycles.

Developed interactive tables using the DT package to compare state-level voting behavior across elections and created data visualizations including scatter plots, time series line graphs, and faceted regional charts. Analyzed vote swings between 2020 and 2024 using regression-style scatter plots with reference lines to evaluate directional shifts in voter behavior.

Extended the analysis by generating a spatial visualization of state-level vote changes and merging results with U.S. geographic data using simple features (sf). Produced a thematic map to highlight regional voting shifts and compare spatial versus tabular interpretations of electoral change.

# Skills & Concepts Used

R programming (tidyverse, dplyr, tidyr)

Data wrangling and long-format transformation (pivoting)

Descriptive statistics (mean, standard deviation)

Data visualization (ggplot2, scatter plots, line charts, faceting)

Interactive tables (DT package)

Geospatial analysis (sf package)

Thematic mapping of election data

Exploratory data analysis (EDA)

# Key Features

Converted election dataset from wide to long format for analysis

Built interactive state-level election comparison tables

Analyzed vote share trends across four presidential elections

Visualized vote swings between 2020 and 2024 using scatter plots with 45-degree reference line

Created time-series line plots for all 50 states (2008–2024)

Highlighted regional voting patterns using faceting and color emphasis

Mapped state-level changes in Trump vote share using geographic data

# Key Insight

Revealed how state-level voting patterns shift over time, showing both stable regional political alignments and significant swing-state volatility, with spatial mapping providing clearer insight into geographic clustering of political change than traditional plots.
